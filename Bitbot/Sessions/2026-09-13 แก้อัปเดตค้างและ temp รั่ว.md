# 2026-09-13: แก้อัปเดตค้างและ temp รั่ว (v1.0.7)

## เป้าหมาย
แก้ [[Known Issues]] ข้อ 12 (หน้าต่างค้างระหว่างดาวน์โหลดอัปเดต) และข้อ 13 (โฟลเดอร์ temp ค้างเมื่ออัปเดตล้มเหลว) แล้ว release โดยทดสอบการอัปเดตจาก v1.0.1

## สิ่งที่ทำ
- เปลี่ยน `maybe_run_update` (บล็อก Tk thread) เป็น `start_update_check` ใน `lib/updater.py`
  - `_fetch_available_update` เช็ค release และ manifest บน worker thread (HTTP 404 = ไม่มีอัปเดต)
  - `messagebox.askyesno` ยังอยู่บน Tk thread
  - `_stage_and_launch_update` ดาวน์โหลด เช็ค hash แตกไฟล์ และเปิด restart helper บน worker thread
  - `_run_in_background` ส่งผลลัพธ์หรือ error กลับ Tk thread ผ่าน `root.after` ทุก 100 ms
  - `_ProgressWindow` (tk `Toplevel` + ttk `Progressbar`) อ่าน `DownloadProgress` ทุก 200 ms แสดง % และ MB
- ข้อ 13: `_stage_and_launch_update` ลบ `stage_root` ใน `except` ทุกกรณี, `_launch_restart_helper` ลบโฟลเดอร์ helper ถ้าเปิด PowerShell ไม่ได้, `_remove_stale_update_dirs` ลบโฟลเดอร์ `rubitdd_update_stage_*`/`rubitdd_update_helper_*` ที่ค้างเกิน 1 ชั่วโมงทุกครั้งที่เช็คอัปเดต
- `main.py`: `run_update_check` เรียก `start_update_check(root, config)` ตัว updater ปิดแอปเองเมื่อพร้อมติดตั้ง
- เพิ่ม `tests/test_updater_install.py` (8 tests)
- commits `08a5c1c`, `8f5dd55` และ GitHub Release `v1.0.7`
